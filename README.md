# Blind Gate Graph

The repository is organized into two complementary workspaces:

- [`research/`](research/README.md) is the evolving theoretical foundation: mathematical, algorithmic, and biological models, questions, and hypotheses. It may contain ideas not yet implemented in the software.
- [`development/`](development/README.md) contains the executable prototype, environment, benchmark data, and tests.

Research is not intended to be a frozen specification or a mirror of the current code. The implementation can inform research, and research can suggest future development, without requiring either side to match the other at all times. The orientation documents are descriptive context for agents and contributors, not rigid requirements.
