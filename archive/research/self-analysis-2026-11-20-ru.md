# Самоанализ проекта (2026-11-20, после сессии 2)

Ориентиры — `goal.md`:
- долгосрочная цель — общий адаптивный агент на анонимных каналах;
- центральный вопрос — декомпозиция на процессы и скрытые состояния при цене, растущей с числом процессов;
- срезы 0–3, уровни доказательств T0–T4, лестница C0–C5.

## 1. Как менялся проект

| этап | что делали | чему научились |
|---|---|---|
| R1–R13 (v10 → v11) | ручные механизмы, подбор по DEV, held-out исчерпаны | баллы растут, но модель — набор заплаток без общей вероятностной модели |
| Срез 0 | статистика, семейство миров FHP с точным фильтром, T1 / T2, документы, протокол с пре-регом | мерить надо умозаключения против точного фильтра, а не только награду |
| Срез 1 и шаг 2 | скрытое состояние; калиброванное ядро v12 | крупнейший рост поведения дал принципиальный шаг (калибровка + VOI): DEV .770 → .891 |
| Срез 2, первая попытка | v13, v14 — вывод контекста внутри v12 | заплатки внутри чужой архитектуры не работают (два провала) |
| Пересмотр тестов, срез 3 | аудит T2, свидетели декомпозиции, мерило d2 / d3 | свидетель показывает, что задача решаема, раньше, чем строится агент |
| Сессия 2 | C0 = v15, F-4, затем разворот к анализу на уровне всего проекта | правило «3 цикла без прогресса → смена направления» сработало: за час решён свидетель среза 2 |

Сквозной вывод: прогресс давали переформулировки из первых принципов (калибровка, генеративная модель, взгляд сверху), а не локальные правки.

Точность прогнозов выросла с ≈ 60 % (D-0 … D-7) до ≈ 90–100 % (D-16 … D-19). Это может значить, что понимание стало лучше, но может значить и то, что прогнозы стали осторожнее.

## 2. Достигнутые цели

1. **Фундамент (срез 0) — достигнута.** Семейство FHP с точным фильтром, T1 / T2 / T3, статистика, протокол с пре-регом. Тесты T0: 56 из 56.
2. **Скрытое состояние в одном процессе (срез 1) — достигнута** (slice-1 A' GC .81 на T1 v1).
3. **Полезное поведение (T3) — достигнута для DEV.** v12 .891 против v11 .770, парно +.121 [+.093, +.150].
4. **Точка решения о ядре после среза 3 — пройдена (F-4)** по заранее записанному правилу: v12 — источник механизмов, а не архитектура.
5. **Доказательство существования для среза 2 — получено.** `lc-sub-add` проходит 10 из 10 строк T2 v1 без знания ролей. Знание ролей оказалось ненужным.
6. **Доказательство существования для декомпозиции — получено на малых мирах.** `decompw`: GC d1 .95, d3 .98, d2 .90.
7. **Улучшение умозаключений агента на T1.** v15 .83 против v12 .66.
8. **Цена понята.** Найден источник сверхлинейности v12. Показано, что предиктор с ограниченными кандидатами (v18) растёт линейно.

## 3. Недостигнутые цели

**По плану C0–C2:**
1. **Срез 2 на уровне агента.** Агент с T2 v1 (вердикты эталона, без потерь в блокировании и торможении) и с DEV не хуже v12. Сейчас есть только сид 0 у v17 и v18. **Это следующий шаг.**
2. **Срез 3: умозаключения около фильтра при линейной цене, включая планирование.** Свидетель есть, агента нет: v15 стоит ×2, и его цена растёт сверхлинейно. На d2 и v1 свидетель тоже недотягивает (.90 / .77).
3. **Цельность: «один математический объект».** Сейчас агенты — смеси v12 со свидетелями, это шаг назад от цели. Целевая факторизованная модель описана в `slice3-plan.md` §8, но не построена.
4. **Честный перенос (T4).** Процедурного генератора миров нет. Последняя проверка на held-out — HELD6, ещё для v11.

**Методические долги, которые я раньше не называл явно:**

5. **T2 v1 больше не held-out для семейства `lc-*`.** Модель придумана после того, как я видел строки T2, а проверки механизма шли на нём же. Нужен независимый набор феноменов, который фиксируется до прогона. Кандидаты: latent inhibition, overshadowing, second-order conditioning, extinction of conditioned inhibition, partial reinforcement в сессиях.
6. **Узость DEV.** Три семейства задач. Открытые проблемы из `results.md` (глубокое исследование, асимметрия выигрыша и потери, отложенная еда с шумом) записаны ещё для v11 и для v12 заново не проверялись.
7. **Вопрос анонимного подкрепления в T2 (Proposal 8)** и малые размеры SR и reinstatement у `lc-sub-add`.

**Дальше по лестнице (не запланировано):** C3 — понятия как типы с экземплярами, C4 — иерархия, C5 — обучение у других агентов. Без C2 не начинать.

## 4. Самокритика

- **Повторяющиеся ошибки процесса:**
  - прогон до пре-рега (D-12);
  - недооценка времени и срыв D-20;
  - профиль снят после оптимизаций, а не до.

  Правило на будущее: время оценивать по изолированному замеру с запасом 20 %, а профиль снимать до любой оптимизации.
- **Разрастание версий.** v10 … v18; каждая смесь добавляет цену. Нужна дисциплина: новая версия только как шаг к модели §8, старые — в архив.
- **Перекос к свидетелям.** Свидетели быстро дают знание, но награду получает агент. Пропорцию надо сдвинуть к агенту.

## 5. Оценка положения

Из запланированной программы C0–C2 закрыты срезы 0 и 1 и точка решения. Срезы 2 и 3 решены на уровне свидетелей, но не агентов.

На главный вопрос `goal.md` есть ответ «в принципе»: факторизованные скрытые причины × мягкое усреднение по ограниченным родителям. Ответа «в агенте с линейной ценой и честным переносом» пока нет.

Грубо — около половины программы C0–C2. Самая рискованная часть впереди: собрать одну модель, сохранить DEV и проверить перенос.
